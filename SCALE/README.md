# S.C.A.L.E

You are a test subject (SUBJ-7355608) in the S.C.A.L.E. (Spatial Calibration and Logistics Engine) testing facility run by Glass Research Inc. You are given the S.C.A.L.E. Device, a state-of-the-art tool that allows you to shrink and expand objects at will. Glass Research scientists have developed a series of puzzles to both test your cognitive function and the overall reliability of the device.

Final game will feature a number of testing chambers with unique puzzles.

## Controls

Move - WASD

Look - Mouse

Shrink/Expand - Q/E

Pickup/Drop - F

## Objective

In Checkpoint 2, the objective is to solve the puzzles for the two test chambers. First one teaches you the main mechanic of scaling/moving objects, while the second one teaches you how to further interact with the world around you and use the device to protect yourself from dangerous hazards.

## Known Problems

- Basic levels -- final deliverable will include multiple levels with different mechanics.
- Lack of first person HUD -- Need to add model for S.C.A.L.E. device
- Little instruction -- Will add contextual hints on pickup and scaling items to first level to teach mechanics.
- Levels thrown together -- Alot of the meshes for the levels are poorly made. Final version will have more polished levels.
- Scaling is still a little janky -- Box can get stuck in you
- Softlocking is possible
